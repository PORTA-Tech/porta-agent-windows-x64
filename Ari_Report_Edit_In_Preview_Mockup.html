What this is

  • The name the client sees moves onto this screen. Today it sends you to the Projects page to fix the single biggest piece of text your client reads, on the last screen before they read it. Your own private name stays underneath, muted, and still never leaves.
  • The result line becomes editable per line, with the question above the box the way every other Ari label works. It was typed days ago on a card and has never been visible here, even though the summary is built from it.
  • Empty stays a first-class state. A blank result line is not an error and does not block sending — the second row shows that plainly.

What deliberately does not change

  • Hours, dates, days worked, the totals and the bars are measured. They are shown with no affordance at all and carry one quiet line saying so.
  • Status stays derived. There is no way to mark something done from this screen.
  • Excluding a line is unchanged — it removes the line, it never edits a number.
  • Ari still does not draft the result line. You write it (decision 5).
  • No new endpoint: both edits already exist behind the local API and are used elsewhere.
